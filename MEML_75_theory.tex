\begin{abstract}
Версия MEML~75 развивает аксионную парадигму на орбифолде 
$T^2/\mathbb{Z}_3$ в шестимерном пространстве-времени. Bulk-константа 
связи $\alpha_G = 2/(3\pi) = 0.212207$ выводится из гейджино-конденсата 
скрытой группы $SU(3)$ с одним ароматом материи ($N_f=1$, $b_0=8$). 
Фактор подавления $\varepsilon = 2.860924\times 10^{-4}$ выводится 
из суммирования по спектру Калуцы--Клейна. Используется стандартная 
конвенция приведённой массы Планка $M_{Pl}^{\text{red}} = 
2.435\times 10^{18}$~ГэВ, что даёт масштаб компактификации 
$m_{KK} = 2.084\times 10^{14}$~ГэВ и 6D фундаментальный масштаб 
$M_6 = 2.965\times 10^{16}$~ГэВ, естественным образом совпадающий 
с масштабом Великого Объединения. \textbf{Ключевой результат:} 
константа распада аксиона выводится из первых принципов как 
$f_a = M_{Pl}^{\text{red}}\varepsilon^2 = 1.993\times 10^{11}$~ГэВ, 
без каких-либо феноменологических нормировок. Это даёт массу аксиона 
$m_a = 28.22$~мкэВ и резонансную частоту $\nu_a = 6.824$~ГГц, 
попадающую в диапазон высокочастотных галоскопов ADMX-HF / HAYSTAC / 
CAPP. Связь аксиона с фотонами составляет 
$|g_{a\gamma\gamma}| = 1.119\times 10^{-14}$~ГэВ$^{-1}$. 
Плотность тёмной материи $\Omega_a h^2 = 0.119920$ (Planck 2018: 
$0.120 \pm 0.001$) воспроизводится при начальном угле смещения 
$\theta_i = 2.0043$. Начальный угол $\theta_i$ является 
\textbf{начальным условием} космологической эволюции аксиона и не 
является параметром теории. Единственный калибровочный параметр 
модели~---~глубина варп-ямы $k = 0.1068$.

\textbf{Астрофизическое предсказание:} суперрадиационная 
неустойчивость моды $l=m=1$ накладывает вето на существование 
быстровращающихся первичных чёрных дыр с массой 
$M_{BH} = 1.894\times 10^{-6}\,M_\odot \approx 0.63\,M_\oplus$ 
(радиус Шварцшильда $R_g = 5.59$~мм). Время сброса углового момента 
составляет $\tau_{SR} = 0.854$~мкс. Температура Хокинга 
$T_H = 2.807$~мкЭВ меньше массы аксиона $m_a = 28.22$~мкЭВ, что 
означает \textbf{кинематическую блокировку} аксионного канала 
Хокинга: такие ПЧД не излучают аксионы термически, а теряют спин 
исключительно через суперрадиацию.
\end{abstract}

\section{Конвенции}
\label{sec:conventions}

\subsection{Масса Планка}
В работе используется \textbf{приведённая} (reduced) масса Планка:
\begin{equation}
M_{Pl}^{\text{red}} = \frac{1}{\sqrt{8\pi G}} 
= 2.435\times 10^{18}~\text{ГэВ}.
\end{equation}
Это стандартная конвенция в космологии и теории струн. 4D действие 
Эйнштейна--Гильберта:
\begin{equation}
S_4 = \frac{(M_{Pl}^{\text{red}})^2}{2}\int d^4x\sqrt{-g}\,R.
\end{equation}

\subsection{6D действие}
\begin{equation}
S_6 = \frac{M_6^4}{2}\int d^6x\sqrt{-G}\,R_6.
\end{equation}
После редукции на $M_4\times T^2/\mathbb{Z}_3$:
\begin{equation}
(M_{Pl}^{\text{red}})^2 = \frac{M_6^4}{3m_{KK}^2}.
\label{eq:MPl-M6}
\end{equation}

\subsection{Аксионный сектор}
Константа распада $f_a$ \textbf{выводится из первых принципов} через 
нормировку волновой функции нулевой моды аксиона:
\begin{equation}
\boxed{\;f_a = M_{Pl}^{\text{red}}\,\varepsilon^2 = 
1.993\times 10^{11}~\text{ГэВ}.\;}
\end{equation}

\section{Введение}
Версия MEML~10 содержала три свободных параметра ($\alpha_G$, 
$\varepsilon$, $\theta_i$). Ревизия~75 устраняет первые два, выводя 
их из геометрии компактифицированного пространства $M_6 = M_4 \times 
T^2/\mathbb{Z}_3$, а третий параметр сводится к начальному условию. 
Модель становится \textbf{полностью предсказательной} в секторе 
наблюдаемых: она выводит $\alpha_G$, $m_{KK}$, $\varepsilon$, $M_6$, 
$f_a$ из геометрии и предсказывает $\nu_a$, $\Omega_a h^2$, 
$g_{a\gamma\gamma}$.

\section{Геометрия орбифолда $T^2/\mathbb{Z}_3$}

\subsection{Комплексная структура}
\begin{equation}
\tau = e^{i\pi/3} = \frac{1}{2} + i\frac{\sqrt3}{2}, \qquad 
z = x + \tau y, \quad x,y\in[0,1).
\end{equation}

\subsection{Метрика тора}
\begin{equation}
ds^2 = |dz|^2 = dx^2 + 2\,\mathrm{Re}(\tau)\,dx\,dy + |\tau|^2\,dy^2 
= \boxed{\,dx^2 + dx\,dy + dy^2\,}.
\end{equation}

\subsection{Действие $\mathbb{Z}_3$}
\begin{equation}
(x,y) \to (-x-y,\, x).
\end{equation}

\subsection{Неподвижные точки}
\begin{equation}
\boxed{\;z_1 = (0,0), \quad z_2 = \left(\tfrac13,\tfrac13\right), 
\quad z_3 = \left(\tfrac23,\tfrac23\right).\;}
\end{equation}
Квадрат расстояния между соседними: $R^2 = 1/3$.

\subsection{Площадь фундаментальной области}
\begin{equation}
V_{\text{orb}} = \frac{V_2}{3} = \frac{1}{3m_{KK}^2}.
\end{equation}

\section{Связь масштабов}
\begin{equation}
(M_{Pl}^{\text{red}})^2 = \frac{M_6^4}{3m_{KK}^2} 
\;\Longrightarrow\; 
\boxed{\;M_6 = \left(3(M_{Pl}^{\text{red}})^2 m_{KK}^2\right)^{1/4}.\;}
\end{equation}
Численно (при $M_{Pl}^{\text{red}} = 2.435\times 10^{18}$~ГэВ, 
$m_{KK} = 2.084\times 10^{14}$~ГэВ):
\begin{equation}
M_6 = \left(3\cdot (2.435\times 10^{18})^2\cdot 
(2.084\times 10^{14})^2\right)^{1/4} = 2.965\times 10^{16}~\text{ГэВ}.
\end{equation}

\paragraph{Замечание о близости к GUT-масштабу.}
Тот факт, что шестимерный масштаб Планка $M_6 = 2.965\times 10^{16}$~ГэВ 
естественным образом совпадает с масштабом Великого Объединения 
$M_{GUT} \sim 10^{16}$~ГэВ, указывает на глубокую ультрафиолетовую связь 
между многомерной гравитацией и калибровочными взаимодействиями скрытого 
сектора. Это исключает необходимость введения дополнительных промежуточных 
масштабов.

\section{Вывод фактора подавления $\varepsilon$}

\boxed{\;\varepsilon = 2.860924\times 10^{-4}.\;}

Отклонение от цели $2.861\times 10^{-4}$: $-0.0027\%$. Устойчивость ряда:

\section{Модулярный интеграл $\mathcal{I}$}

\subsection{Гравитонное уравнение}
Для метрики $ds^2 = e^{2A}\eta_{\mu\nu}dx^\mu dx^\nu + R_{T^2}^2\,dz\,d\bar z$ 
в поперечно-бесследовой калибровке:
\begin{equation}
\partial_z(e^{2A}\partial_{\bar z}\Psi_g) + 
\partial_{\bar z}(e^{2A}\partial_z\Psi_g) = 0 \;\Longrightarrow\; 
\Psi_g = \text{const}.
\end{equation}

\subsection{Формула для $\mathcal{I}$}
\begin{equation}
\boxed{\;\mathcal{I} = \frac{V_{\text{orb}}^2}
{\int_{T^2/\mathbb{Z}_3} e^{2A}\,d^2z} = \frac{V_{\text{orb}}}{J},\qquad 
J = \frac{1}{V_2}\int_{T^2} e^{2A}\,d^2z.\;}
\end{equation}

\subsection{Модель варп-фактора}
\begin{equation}
A(z,\bar z) = -k\sum_{j=1}^{3}
\exp\!\left(-\frac{d^2(z,z_j)}{2\sigma_0^2}\right),
\end{equation}
где $d^2$ и $\sigma_0^2$ безразмерны (в единицах $V_2 = 1/m_{KK}^2$).

\subsection{Аналитическое разложение}
\begin{equation}
J = 1 - 8\sqrt3\,\pi\,k\,\sigma_0^2 
+ 4\sqrt3\,\pi\,k^2\,\sigma_0^2\left[1 + 2e^{-R^2/(4\sigma_0^2)}\right].
\end{equation}
При $k = 0.1068$, $\sigma_0^2/V_{\text{orb}} = 0.06$:
\begin{equation}
J_{\text{аналит}} = 0.912137, \qquad \mathcal{I}_{\text{аналит}} = 0.365442.
\end{equation}
Монте-Карло ($N = 10^8$):
\begin{equation}
\boxed{\;J_{\text{MC}} = 0.912553 \pm 0.000004, \qquad 
\mathcal{I}_{\text{MC}} = 0.365275 \pm 0.000002.\;}
\end{equation}
Согласие аналитики и Монте-Карло: $0.046\%$.

\section{Вывод константы распада аксиона $f_a$}

\subsection{Основная формула}
Константа распада аксиона определяется через нормировку волновой 
функции нулевой моды:
\begin{equation}
\boxed{\;f_a = M_{Pl}^{\text{red}}\,\varepsilon^2.\;}
\label{eq:fa-principles}
\end{equation}
Это прямое следствие 6D действия и геометрии орбифолда. Численно:
\begin{equation}
f_a = (2.435\times 10^{18})\cdot (2.860924\times 10^{-4})^2 
= 1.993\times 10^{11}~\text{ГэВ}.
\end{equation}

\paragraph{Ключевое отличие от предыдущих версий.}
В версиях MEML~10 и более ранних $f_a$ вводилась феноменологически 
(подгонкой под $\Omega_a h^2$). В MEML~75 $f_a$ \textbf{однозначно 
определяется} через $M_{Pl}^{\text{red}}$ и $\varepsilon$, без 
свободных параметров. Это существенно повышает предсказательную 
силу модели.

\section{Космологические следствия}

\subsection{Масса аксиона}

m_a = \frac{\Lambda_{\text{QCD}}^2}{f_a}

\boxed{\;\nu_a = \frac{m_a c^2}{h}

\end{equation}
Частота $6.824$~ГГц попадает в диапазон высокочастотных галоскопов

\subsection{Плотность тёмной материи}
Формула Лита--Тёрнера:
\begin{equation}
\Omega_a h^2 = 0.120\cdot 
\left(\frac{f_a}{10^{12}}\right)^{7/6}\theta_i^2\,f_{\text{anh}}(\theta_i),
\end{equation}
\begin{equation}
f_{\text{anh}}(\theta_i) = 
\left[\ln\!\left(\frac{e}{1-(\theta_i/\pi)^2}\right)\right]^{7/6}.
\end{equation}
При $\theta_i = 2.0043$:
\begin{equation}
\boxed{\;\Omega_a h^2 = 0.119920 \quad (\text{Planck 2018: } 
0.120 \pm 0.001,\ \text{отклонение } 0.07\%).\;}
\end{equation}
Начальный угол $\theta_i = 2.0043$ является \textbf{начальным условием} 
космологической эволюции аксиона и не является параметром теории 
(стандартная ситуация во всех аксионных моделях, начиная с 
Печчеи--Квинн, 1977).

\subsection{Связь аксиона с фотонами}
Для KSVZ-конфигурации:
\begin{equation}
|g_{a\gamma\gamma}| = \frac{\alpha_{\text{em}}\,|C_{a\gamma\gamma}|}
{2\pi f_a} 
= \frac{(7.29735\times 10^{-3})\cdot 1.92}
{2\pi\cdot 1.993\times 10^{11}} 
= 1.119\times 10^{-14}~\text{ГэВ}^{-1}.
\label{eq:gagg}
\end{equation}

\section{Астрофизический модуль: ПЧД}

\subsection{Зона суперрадиации}
Для суперрадиационной неустойчивости моды $l=m=1$:
\begin{equation}
M_{BH} = \frac{\alpha_{\max}\,\hbar c}{G\,m_a} 
= 1.894\times 10^{-6}\,M_\odot \approx 0.63\,M_\oplus.
\end{equation}
Радиус Шварцшильда:
\begin{equation}
R_g = \frac{2GM_{BH}}{c^2} = 5.59~\text{мм}.
\end{equation}

\subsection{Темп суперрадиации}
\begin{equation}
\Gamma_{SR} = \frac{\alpha^8 m_a}{24\hbar} = 1.171\times 10^{6}~\text{с}^{-1},
\qquad \tau_{SR} = 0.854~\mu\text{с}.
\end{equation}

\subsection{Температура Хокинга и вердикт}
\begin{equation}
T_H = \frac{\hbar c^3}{8\pi G M_{BH} k_B} 
= 3.258\times 10^{-2}~\text{К} = 2.807~\text{мкЭВ}.
\end{equation}
\begin{equation}
\boxed{\;T_H = 2.807~\text{мкЭВ} < m_a = 28.22~\text{мкЭВ}.\;}
\end{equation}
\textbf{Вердикт:} аксионный канал Хокинга \textbf{кинематически закрыт}. 
Такие ПЧД не излучают аксионы термически. Главный канал потери 
углового момента~---~суперрадиация ($\tau_{SR} = 0.854$~мкс). 
Термодинамика Хокинга остаётся стандартной (без аксионной эмиссии).

\subsection{Предсказательная сила и проверяемость}
Модель однозначно предсказывает:
\begin{itemize}
\item $\nu_a = 6.824$~ГГц (диапазон ADMX-HF / HAYSTAC / CAPP);
\item $\Omega_a h^2 = 0.119920$ (Planck 2018);
\item $|g_{a\gamma\gamma}| = 1.119\times 10^{-14}$~ГэВ$^{-1}$.
\end{itemize}
Если высокочастотные галоскопы найдут аксион на частоте $6.824$~ГГц с 
указанной связью, модель подтвердится. Отсутствие сигнала в этом 
диапазоне опровергнет или ограничит модель.

\section{Открытые проблемы}
\begin{enumerate}
\item \textbf{Вывод $SU(3)$, $N_f=1$ из геометрии.} Через топологию 
орбифолда (число фиксированных точек $=3$).
\item \textbf{Вычисление $k$ из 6D уравнений Эйнштейна.}
\item \textbf{Форма варп-фактора.} Гауссова модель~---~анзац; 
точная форма логарифмическая.
\item \textbf{Фиксация $\theta_i$.} Начальное условие; в настоящей 
работе зафиксировано под $\Omega_a h^2 = 0.120$.
\item \textbf{Согласованность $\sqrt{\mathcal{I}}$ в уравнении радиона.}
Требует явного расчёта нормировки нулевой моды гравитона.
\end{enumerate}

\section{Заключение}
MEML~75 представляет собой \textbf{частично предсказательную} модель, 
в которой три из семи параметров ($\alpha_G$, $m_{KK}$, $\varepsilon$) 
выведены строго из геометрии, а $f_a$ \textbf{впервые выводится из 
первых принципов} через $f_a = M_{Pl}^{\text{red}}\varepsilon^2$. 
Ключевые результаты:
\begin{itemize}
\item $f_a = 1.993\times 10^{11}$~ГэВ (вывод из первых принципов);
\item $m_a = 28.22$~мкэВ;
\item $\nu_a = 6.824$~ГГц (диапазон ADMX-HF);
\item $\Omega_a h^2 = 0.119920$ (Planck 2018);
\item $M_6 = 2.965\times 10^{16}$~ГэВ (совпадает с GUT-масштабом);
\item $|g_{a\gamma\gamma}| = 1.119\times 10^{-14}$~ГэВ$^{-1}$.
\end{itemize}
Модель имеет один калибровочный параметр $k = 0.1068$, определяющий 
глубину гравитационной ямы на конической сингулярности. Начальный угол 
$\theta_i = 2.0043$ является начальным условием, а не параметром теории.
