## О проекте

**MEML 75** — версия геометрической модели идентичности частиц на 
орбифолде $T^2/\mathbb{Z}_3$ в шестимерном пространстве-времени. 

Версия B использует стандартную **приведённую массу Планка** 
$M_{Pl}^{\text{red}} = 2.435\times 10^{18}$ ГэВ, а константа распада 
аксиона $f_a$ **впервые выводится из первых принципов** как 
$f_a = M_{Pl}^{\text{red}}\varepsilon^2$. Это принципиальное отличие от 
MEML 74, где $f_a$ подгонялась феноменологически.
