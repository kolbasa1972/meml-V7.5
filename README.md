# MEML 75 — Модель единого мирового листа

**Версия 75** | 2026

---

## О проекте

MEML 75 — версия геометрической модели идентичности частиц на орбифолде $T^2/\mathbb{Z}_3$ в шестимерном пространстве-времени. Модель устраняет два из трёх свободных параметров исходной версии путём вывода их из геометрии компактифицированного пространства.

## Ключевые результаты

| Величина | Значение | Статус |
|---|---|---|
| α_G | 2/(3π) = 0.212207 | Выведен из SU(3), N_f=1 |
| m_KK | 1.044 × 10¹⁵ ГэВ | Выведен из уравнения радиона |
| M_6 | 1.485 × 10¹⁷ ГэВ | Выведен из редукции |
| ε | 2.861 × 10⁻⁴ | Выведен из KK-суммирования |
| k | 0.1068 | Калиброван под I = 0.3653 |
| I | 0.365275 | Условно выведен |
| θ_i | 0.9483 | Начальное условие |
| Ω_a h² | 0.119832 | Совпадение с Planck 2018 (0.02%) |
| ν_a | 1.362 ГГц | Таргет ADMX |

## Статус параметров

- **Строго выведены:** α_G, m_KK, M_6, ε (4 параметра)
- **Условно выведен:** I (1 параметр, требует k)
- **Калиброван:** k = 0.1068 (1 параметр)
- **Модельный:** σ₀²/V_orb = 0.06 (1 параметр)
- **Начальное условие:** θ_i = 0.9483 (1 параметр)

Модель является **частично предсказательной**: при заданных параметрах она однозначно предсказывает Ω_a h², f_a, m_a, ν_a.
